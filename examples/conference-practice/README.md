# 同口径的数值、明细与上下文

```bash
python examples/conference-practice/run_demo.py --out tmp/conference-demo
```

输出两个模型、两个SQLite库、4份执行结果、2份上下文包及示例报告。输出目录需为空，不覆盖已有工作。

交通：T1主体中开业危货记录的 company_id 为 A、A、NULL，三种计数分别3/2/1。另有T2、停业、普货数据用于排除。只输出company_id也必须保留过滤。

零售：T1已支付100+30=130，退款50和T2支付900排除；漏状态会得180，漏主体会得1030。明细必须是100和30。条件是示例设定，不是行业默认政策；tenant条件不是鉴权。

预期在写数据前直接约定并写入示例，不从被测SQL产生。模型推断的对象仍是候选。更新过滤后旧上下文拒绝使用，重新生成才可消费。样例用于学习与工具回归，不能拿来证明模型在未见问题上的泛化准确率；独立评审应另造数据并先写预期。
