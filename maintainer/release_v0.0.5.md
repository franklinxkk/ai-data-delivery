# v0.0.5：从部分材料到有证据的语义交付

新增持久补齐闭环：记录当前用例、缺口、候选与责任人回答，生成可审阅补丁，确认后应用并导出模型与决策记录。新增复合/异名关联键和查询粒度风险检查、六类 SQLite 数据约束、可搜索的离线关系/映射/证据视图。

修复会产生错误成功结论的边界：缺报告不再默认通过门禁；回归报告绑定模型、用例和数据快照；未知、过期证据与 SQL 错误阻断验证；豁免需具体用例、依据、责任人和期限。单表编译保留完整过滤，拒绝跨表前缀和不支持的 SQL，不再通过去前缀隐藏问题。

保留原有 27 个命令入口，新增 4 个命令。`release_gate` 默认采用 validated profile，旧报告与缺字段豁免需迁移；只做静态检查可显式选 static。完整迁移与限制见仓库 references/delivery-playbook.md。

验证：58 项自动化测试、五领域 Mock、完整补齐示例通过；31 个命令帮助入口与本地文档引用检查通过；浏览器实测搜索/筛选/关系与确认详情。另用归档模型和 SQLite 做只读比较，43 个结构化指标新旧编译结果一致。这些证据不构成本版真实 AI 端点、客户验收或国标符合性证明。

资产：`ai-data-delivery_v0.0.5.skill`、`SHA256SUMS.txt`。包内 BUILD.json 记录源码提交、版本、运行文件哈希。文件完整性不代替业务正确性；安装行为需按具体宿主确认。

本版不包含通用跨表 SQL 编译、OWL 推理、Ossie 适配器或实时运行血缘。标准参考已区分适用范围与未实现能力。
