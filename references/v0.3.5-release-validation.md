# v0.3.5 — actual validation / 实际验证

2026-11-18。本版按 CLI 工具范围封板：导入结构 → 按需编辑图谱 → 导出与本机读取。保留已发布的 v0.3.4，不增加系统后台、常驻服务或生产查询执行器。安装 ZIP 的 `BUILD.json` 记录实际源码提交及逐文件 SHA256；Release 的 `SHA256SUMS.txt` 对应最终安装包。

## 改了什么，以及为什么

| 试用发现 | 本版修正 |
| --- | --- |
| 对象、字段、关系逐项保存，跨资产依赖容易遗漏 | 现有 `edit --file` 支持资产数组，一次事务保存；复用确认授权、证据检查、修订冲突、回滚与操作回执 |
| 每次查身份要加载整个项目历史 | `state --summary` 返回资产身份、来源修订和待处理组；需要原文时再读取完整内容 |
| 根指标遗漏副表、映射、关系或连接键，包仍可能结构自洽 | 新增只读 `inspect --id` 提示已知遗漏、无对应字段的连接键、未确认依赖及来源变化；不替人增加关系或确认业务含义 |
| 整段政策重复填入多个指标属性，或被复制为无修订的人工断言 | 短建模指引明确分开粒度、单位、时间、包含和排除；检查器提示重复属性及与已导入材料相同的人工断言，保留人工判断 |
| 接收 Agent 多次取证、搜索失败后猜 ID | `sources` 支持多个 ID、去重、分页及缺证身份；无匹配时返回同范围内的分页候选；上下文明确本页和全部必需身份 |
| 把所有步骤都当成必需流程 | README 与 Skill 保留两条命令的结构草稿路径；业务建模按需读短指引，不要求先建立问题、验收记录或启动界面 |

## 不能合并为“全部通过”的结果

初次冷读作者没有通过：出现泛化对象、遗漏实际依赖、无修订的政策复制以及错误参数。随后修复工具提示和指引，保留失败材料，再完成上述修正后调用。另一路 6.1 terra 作者试用未完成，不能计作十二行业成功。修正后试用受到反馈指导，不能冒充首次无帮助成功，也不能据此声称零门槛或所有角色都能立即上手。

独立接收的五项部分满足来自输入边界：零售退款跨期截止未定；地产面积物理单位未定；能源缺测不能补零；医疗未映射身份不能保证总自然人数完整；酒店未定占用与可售房晚交集、零分母口径。本版保留这些未知，不编造业务规则。其他领域的并列版本、所有权、汇率等未给定规则也不据此扩展。

`inspect` 只检查已声明图谱，不证明所有业务依赖齐全；`complete` 不表示业务答案正确。离线包无法自证最新或自动撤销。所有行业数据均为合成材料，未完成真实客户验收、PostgreSQL/MySQL 生产联调、Neo4j 生产验收、负载测试或跨宿主认证。本次没有新的 ClawHub 复扫或 SkillHub 官方评分；安全说明中的本地修复不代表平台撤销告警。
