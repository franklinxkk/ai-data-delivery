## Reproduce / 复现

```bash
python -X utf8 -m unittest discover -s tests -v
python -X utf8 maintainer/check_cross_domain.py --out "./work/四领域 回归"
node tests/test_knowledge_ui.cjs
node tests/test_scope_ui.cjs
node tests/test_graph_layout.cjs
node tests/test_i18n.cjs
```

Use a new/empty four-domain output directory. For browser validation, start a fresh example with `scripts/start.py --project NEW_PATH --example equipment --language en` (or `zh`), set `EVIDENCE_DIR`, then run `maintainer/browser_bilingual.cjs LOCAL_URL en` (or `zh`). Run `browser_questions.cjs` or `browser_acceptance.cjs` afterward on the prepared exercise. Playwright and Edge are maintenance dependencies; neither enters the runtime package.

Two harness problems were corrected, without weakening product expectations: the new browser test initially omitted the existing session token on a state read, and the English initialization test was initially pointed at an already-reviewed Chinese project. Final runs used the token and a fresh English project. A test also initially read `request` instead of the documented `scope.request` envelope; the assertion was corrected. / 上述失败分别属于测试读状态漏 token、初始化脚本使用旧项目，以及断言读错返回层级；已修正脚本后重跑，不计为产品通过证据。

## Distribution and limits / 安装包与边界

The runtime allowlist excludes tests, maintainer utilities, node_modules, caches, private projects/databases and local evidence. Packaging verifies archive CRC and source equality; `BUILD.json` contains every included runtime file hash. Installation verification and stopped-server reader results are recorded with the delivery evidence after building the committed source. / 安装包只含允许的运行文件与公共样例，包校验和最终解压试用记录随交付证据保存。

This is local Windows/Python 3.12.10 synthetic verification. It does not establish live database change capture, semantic extraction quality, real customer acceptance, business-answer correctness, production security, a new three-model evaluation, or a new ClawHub/SkillHub audit. The project has no automatic model invocation, business action execution or database monitoring. Platform submissions remain the owner's task. / 本次没有冒充生产数据库联调、客户验收、三模型重测或 ClawHub／SkillHub 平台审查。问题预期与人工记录不构成自动验证的业务答案。
