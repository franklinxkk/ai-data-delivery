# 0.3.6 · release verification

This patch keeps a single local project, a temporary browser editor and a portable semantic package. Neither the installation ZIP nor the test fixtures require private schemas, a database credential or a model key. Production queries, business decisions and cloud-host compatibility were not certified.

| Area | What was checked |
|---|---|
| Import and handoff | A real schema-only MySQL dump was parsed locally without executing SQL. Table identities, column paths and every declared foreign-key endpoint and ordered key pair were independently compared with the draft. A source-linked business term was exported and read in a separate process. Parser warnings about dump statements, constraints and table options remain visible. This is not complete interpretation of MySQL DDL. |
| Large responses | Compared ordinary CLI responses and verbose responses from the **same existing ZIP**. Compact receipts retain selection boundaries, warning/issue counts, the exact selected quote and the source fragment. Full inventories remain available with `--full-scope`; authoring has `--full-output`. No input schema or customer package is distributed. |
| Visual authoring | A local browser trial used synthetic data. It exercised object/relationship creation, type-filtered endpoints, citations with the original source revision, a focused graph, and showing external CLI changes on an idle page. A screenshot is a view of saved state, not an independent business approval. |
| Integrity and editing | Tested whole-model versus explicit-root export; rejecting stale or unversioned replacement of an existing asset; refusing a nonexistent project in read-only commands; and keeping historical snapshots unchanged when a policy gains a new paragraph. Existing ZIPs can still be read. |

Reproduce with `python -X utf8 -m unittest discover -s tests` and the Node scripts in `tests/*.cjs`. The release ZIP is generated by `maintainer/build_skill.py` from tracked runtime paths at a clean Git commit. The GitHub release publishes the ZIP and its SHA-256 checksum.

Release checks on Windows: 494 Python tests, 489 passed and 5 skipped; all five Node test scripts passed. A headless Chrome trial with synthetic records observed an external CLI write on an open graph and verified that an in-progress form retained its input across a revision conflict. Saving a relation preserved its exact source quote and fragment identity. The skill metadata validator also passed.

中文：验证的是本地建模、结构与证据交接。字段或外键正确不等于监管指标已经可计算；结构草稿不会自动确认为业务定义。真实 SQL、客户资料和私有试验输出均未纳入公开安装包。
