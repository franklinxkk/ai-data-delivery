## Findings fixed / 本轮修复

- Selection redraw could prevent a node's native double-click event from opening the editor. The canvas now recognizes a second activation of the same node; real browser double-click/save/reload passed.
- Same-named assets of different kinds, such as a business object and its physical table, were incorrectly treated as mergeable duplicate identities and blocked publication. Identity review now compares merge-compatible kinds; same-kind conflict rejection remains covered. Reader search still returns multiple meanings for disambiguation.
- Fixed authored business proposals must follow DDL confirmation, so their dependency fingerprints match the reviewed physical definitions. Modified exercise materials reject canned proposals and remain available for a normal host task.
- Static interface translations preserve interpolated domain values, zero, false, IDs and evidence. Unsaved edits are not discarded by language switching. Core validation errors include actionable English/Chinese messages; legacy tool reports or unknown diagnostics retain their original detail when no translation is available.

Two acceptance-script mistakes were corrected separately from product code: the initial browser script looked for a metric in the Business-only view, and the initial unit test passed a scalar ID to a list-based Python context API. Final runs used All knowledge and the documented argument shape. Failed exploratory runs are not counted as passed evidence.

## Reproduce / 复现

From the source repository:

```bash
python -m unittest discover -s tests -v
node tests/test_knowledge_ui.cjs
node tests/test_scope_ui.cjs
node tests/test_graph_layout.cjs
node tests/test_i18n.cjs
```

For actual browser checks, install Playwright in a development environment, start a **new** example project and run `maintainer/browser_bilingual.cjs LOCAL_URL en` (or `zh`). Supply `BROWSER_PATH` when Edge is not installed at the default Windows location, and `EVIDENCE_DIR` for output. Browser/test dependencies are not runtime installation requirements.

Runtime packages are built from tracked allowlisted files by `maintainer/build_skill.py`. Source tests, executable mocks, generic lifecycle utilities, caches, project databases and private evidence directories are excluded. Distribution verification checks archive integrity and every BUILD file hash before exercising installed entrypoints.

## Evidence limits / 未覆盖范围

This is a synthetic exercise on Windows with Python 3.12.10 and headless Microsoft Edge. It is not a real customer policy sign-off, production database integration, real loan execution, first-time-user study, multi-user authorization audit, performance certification or a new ClawHub/SkillHub result. Browser-native file-pickers follow browser/OS language. Knowledge, source quotations and external/legacy diagnostics may intentionally retain their original language.

Marketplace submission is performed by the owner after this handoff. No platform pass or six-dimension score is inferred from local tests. Existing four-domain/three-model evidence applies only to its recorded earlier baseline; this iteration does not relabel it as rerun evidence.
