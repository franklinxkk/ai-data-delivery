## Automatic versus reviewed / 自动与人工边界

Only explicitly enabled nonunique-index metadata changes synchronize automatically, and only while generated physical definitions remain untouched. This does not approve business meaning or bypass affected-question regression. Table/column additions, disappearance, rename, types, defaults, constraints, comments and mappings require review. A missing table can mean permission loss. Read failure does not alter the graph or observation baseline. Scans are on demand; there is no CDC service or scheduled listener. / 仅明确授权、人工未改动的非唯一索引元数据可以自动同步，不能跳过问题回归。其他结构及业务映射变化均需核对；表不可见不等于删除；读取失败保留图谱与基线。当前是按需扫描，没有 CDC 或定时监听。

## Not established / 未证明项

- No production database, real customer policy/threshold or enterprise authorization acceptance. Four-domain materials are authored synthetic fixtures, not an LLM extraction-quality benchmark. / 未连接生产库、验收真实业务口径或企业权限；四领域是预编写合成夹具，不是模型抽取质量评测。
- No new three-model evaluation, user study, ClawHub rescan or SkillHub score is claimed. Local tests and import success do not substitute for external evaluation. / 本轮未重跑三个模型、用户研究或外部平台评测，不以本地结果冒充。
- Neo4j is an optional snapshot export, not the workbench's primary database, live synchronization service, authorization gateway or rule executor. Local file imports require server settings documented in the export README. Managed-service CSV upload was not tested. / Neo4j 是快照出口，不是工作台主存储、实时同步、权限网关或规则引擎；未验证托管服务上传。
- No background monitoring, inferred column-rename matching, automatic business-rule rewrite or unregistered dependency discovery. “No linked question” means no recorded dependency, not no business impact. / 不自动监听、不猜测字段改名、不改写业务规则；未登记依赖无法推断业务影响。
- A published offline package remains a fixed observation. Freshness outside that snapshot is unknown. / 已发布文件只代表固定观察，离线无法确认最新状态。
