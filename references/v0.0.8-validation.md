## 本版变更清单（对照评审意见）

- **ingest_ddl.py（P0）**：平衡括号扫描替代非贪婪正则提取表体；单表失败记 `parse_failures` 台账；`;` 后重新同步 CREATE/EOF；`parse_sql` 返回 `(tables, failures)` 二元组
- **check_model.py**：E00 拆分——有 ontology.entities 无 datasets 降为 W14 草案态（exit 0），全空才 E00；E09 的 WARN 误标改为 W13；SENSITIVE_PAT 扩充（ssn/passport/bank_card/email/护照/银行卡/社保卡/医保/邮箱）；新增 W15（unit=% 的 ratio 无 display_scale）、W16（filters/expand 取值不在字段 enum 内）；头部规则清单同步；接入共享 `top_shape_error` 顶层型别校验
- **_contract.py**：`load()`/`digest()` 缺失文件与非法 YAML 干净报错（exit 2）；新增 `top_shape_error()`；此前已有 minimal_env/guard_endpoint
- **19 个脚本**：裸 `yaml.safe_load(open(...))` 共 32 处统一迁移到 `_contract.load()`（harvest_metrics/patch_model 因自带 load 同名走别名/委托）
- **_sql.py**：extra_where 黑名单补 LOAD_EXTENSION/READFILE/WRITEFILE（REPLACE/GLOB 为合法函数，刻意不放行也不拦）
- **guide_model.py**：--pack 支持裸包名解析 starter_packs；stale answers 报错带当前 revision 与修复指引；三态标签 `[AI建议]` 改 `[候选·推断]`（脚本不调用任何模型的边界声明）
- **run_eval.py**：模式 A 接入端点守卫 --allow-remote（第五个接守卫的脚本）
- **detect_isomorphic.py / profile_db.py**：--out 目录防御前置；profile_db 补 db 存在性检查
- **impact_analysis.py**：target 未找到时列出合法形式与可用数据集/指标/概念清单
- **release_gate.py**：not_ready 按 gate 附 actionable hint 并**打印到 console**（此前只写 JSON）；模型顶层型别前置校验
- **patch_model.py**：写入前自动 `.bak` 备份
- **文档**：SKILL.md frontmatter 补 license/language/capabilities 机器可读声明；README 首句过曝收口（治理交付过程，不承诺"问数答得对"）、「AI 建议」统一改「候选项（宿主 Agent 生成，脚本存证）」、交通证据链接；contract.md 明确 is_a 仅分类声明无属性继承；onboarding.md 补 answers.json 两个易错点；tools.md 加「按角色找工具」表；新增 quickstart-fde/pm/infocenter 三篇角色快速通道；references/evidence/traffic/ 脱敏证据入仓；SECURITY.md 重写；general.yaml 的 GB/T 48000.3 措辞软化为「参考（非符合性声明）」
