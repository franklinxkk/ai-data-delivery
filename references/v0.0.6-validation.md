# v0.0.6 验证记录

验证日期：2026-09-28。运行环境：Windows、Python 3.12、PyYAML 6.0.3。版本标识以 Release 标签、源码提交和包内 BUILD.json 为准。

## 本版变更

新增 `ontology` 本体声明层（实体/属性/谓词/落地方式）与合同投影对账（ontology_ref）；概念词表属性（synonyms/forbidden/domain/有效期）；比率指标 `on_zero_denominator` 显式策略；评测 `answer_must_not_contain` 禁用词断言；诊断取证瀑布（L0→L4，文档级）；可视化本体面板；guide_model 先业务后物理的缺口顺序。本体段是声明式事实清单，不做推理、不是 OWL/SHACL。
