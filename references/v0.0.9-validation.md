## 本版变更清单（对照运智管家实测问题单）

- **check_model.py**：E14 实体引用接受 name|uid 双写法（uid 投影归一为 name，W07 不误报；is_a 与关系端点仍按 name，文档既定行为）；新增 W17（structured 指标同义词 <3）、W18（模板缺 time_field/同义词 <3）、E18（模板结构非法）；check_templates 接入主流程；model_index 与 drift 破坏检查覆盖 templates；lint 汇总行补模板计数
- **patch_model.py**：dump 改原子写（tmp + os.replace，OSError 等待 0.6s 重试一次——Windows 安全软件高频写盘拦截的实测对策）；核心逻辑抽为 apply_syn/apply_struct/apply_set/apply_fixuid 可复用函数；新增 **batch** 子命令（ops.yaml 逐条应用、单条失败回滚该条并继续、末了一次写入、任一失败 exit 1，--db 作用于全部 struct op）；新增 **fixuid** 子命令（--map/内置词表/哈希回退，逐条打印供审阅）
- **promote_draft.py（新）**：盘点指标 → ✅ 可直接合入（ops.yaml）/ 🔶 映射待确认（ops_review.yaml）/ ⛔ 需业务定义 / 📋 明细模板（templates_draft.yaml）+ 提升清单.md；字段三级解析（物理名直中 → cn 全等唯一 → cn 近似唯一标【推断字段】）；枚举值近似提议标【值待确认】；比率/派生引用检测；profile 类宽表粒度存疑提醒；时间字段优先 stat_date；--syn-map 叠加领域同义词素材；⚠️ 表名未映射可见桶
- **contract.md**：新增「明细查询模板（templates）」合同段——真实项目实测约半数问数需求是"列出来"而非聚合数字，明细查询是一等资产不挤进 metrics
- **gen_metadata.py**：列 cn 优先取 DDL COMMENT（标 cn_source 待审），无 COMMENT 才占位
- **harvest_metrics.py**：mapping_from_meta 跳过【待填】占位 sources 并点名提醒（此前静默无映射）
- **visualize_model.py**：-f 别名与 check_model 对齐
- **mocks**：新增 crm/oa/education 三域（语义模型 + 确定性造库 + gold 用例）；既有 5 域指标同义词用 batch 补齐 21 条（dogfooding），retail 增明细模板示例
- **文档**：README 重构——八阶段故事地图章节（链接 references/story-map.md 完整版：命令/产出/角色泳道/3-4 周时间账本/三条铁律）、运智管家案例段、Star 邀请；tools.md 补 batch/fixuid/promote_draft；SKILL.md version 0.0.9
