## 过程中遇到的限制

初次沙箱运行 HTTP 用例被本地套接字权限阻止，改在允许回环访问的测试环境重跑；缺少的固定版本数据库驱动补入项目虚拟环境后重跑通过。Edge 的一次后续启动崩溃改用 Chrome 复验。另一次测试脚本在保存尚未完成时点生成包，已增加真实完成等待；这些环境/脚本问题与实际产品缺陷分别处理。

没有调用生产数据库、真实业务写入或外部执行服务。连接器单元/模拟验证不等于 PostgreSQL/MySQL 生产联调；没有重新声称 Neo4j 生产集成验收通过。

## 使用边界

新版问题包为 semantic-package/1.1；0.3.4 读取器仍接受旧1.0包。旧包可以读定义，在 control 入口返回 NO_CONTROL。已有项目不自动补绑定、不覆盖确认历史；需按实际字段与证据提出变更。新包请配套0.3.4读取器。

控制单是受约束的交接信息，本版不提供可执行 SQL、通用 JOIN 规划、完整可视化查询编排、MCP 执行服务、运行时权限或离线自动撤包。query/calculate/act 返回 blocked；explain_only 仍需核对缺口。未证明零门槛、准确率提升或生产可用性。
